## 2. Done this session

### 2.1 Compiler (azora-lang, committed in b31722d)

- **`inline for` almost everywhere.** It now expands in lambdas, `using`, `defer`, free functions and tests:
  - New `frontend/AstMapper.kt`, an exhaustive AST mapper.
  - The ReflectDecoExpander unrolls loops that declare locals into their own scope (`ownScope`).
  - The monomorphizer handles field reflection (`f.name`, `f.typeName`, field annotations) in free functions and tests.
- **A reactive lambda parameter called from a nested child block** no longer produces unlinkable LLVM:
  - The capture scan reads the call receiver.
  - The resolver records the capture.
  - Explicit capture lists were added in std `async.az` and `thread.az`.
- **LLVM ownership fixes:**
  - Defer slots snapshot their bindings. Before, this caused heap corruption.
  - By-value captures are copied (`copiedCapture`).
  - Copy-on-return for unowned places.
  - `IfExpr` branches no longer alias locals.
  - `Array.insert` is implemented.
- **Erased generics.**
  - Ordinary generics are compiled once for every type. So `T.typeName`, and therefore `store<T>` or `ensureStorage<T>` reached from a generic body, folded to the literal "T". Every lookup then hit a storage named "T".
  - This is why **no click worked anywhere in Studio**.
  - It is now a compile error, with the hint to pass the `Storage<T>` in from a caller that names the type (`CtfeEvaluator.erasedTypeParams`, `ErasedTypeNameTest`).
- **Temporaries passed into calls are freed.**
  - Constructors, fresh call results and array literals lent to a by-value or `&` parameter used to leak on every call. Math, ECS and UI code all leaked this way.
  - `OwnershipCleanup` now marks such arguments `__temporary`, and `LlvmCodegen.emitCall` frees them after the call.
  - Guards:
    - only callees whose every result is fresh (`freshResults`);
    - never `!` parameters, or callees returning a borrow;
    - never arrays of erased elements;
    - `__alloc` and `__derefAssign` count as keeping their argument (`keptByIntrinsic`);
    - so does a parameter bound into an owning local.
  - The interpreter and WASM treat `__temporary` as a pass-through.
- Also fixed:
  - Enum shorthand inside decorator arguments.
  - `serialAsReal` replacing `serialAsDouble`.
  - Pack field defaults.
  - Bridge packs excluded from templates (`engine.math` had made `Int` a template).
  - Receiver names in recursive react functions.
  - `IfExpr` literal adoption.
  - Annotated declarations from other modules are injected (`StdlibInjector`).
- New or extended tests: `ReflectedFieldTest`, `BridgePackTemplateTest`, `ErasedTypeNameTest`, plus additions to `ReflectDecoExpanderTest`, `LlvmCaptureParityTest` and `LlvmRegressionExecTest`.

### 2.2 Engine (azora-engine, uncommitted)

- **ECS performance** (`azora-ecs/src/ecs.az`):
  - `Storage<T>` is now a **sparse set** (`sparse: Array<Int>`, entity id → dense index + 1). `storageIndexOf` is O(1) and allocation-free.
  - Removal keeps insertion order and renumbers the tail.
  - `storageGetOrDefault` borrows its default (`T&`).
- **UI ECS performance** (`azora-ui`):
  - A new `Children` component keeps each node's children in sibling order; the root's list is `Composition.rootChildren`.
  - `claim` and `findChild` look among the parent's own children, starting at the expected position, so an unchanged recompose is O(1) per node.
  - `childAt` and `childCount` are lookups.
  - `commit` gathers unclaimed nodes once, removes leaves first, then trims stale list entries.
  - **Result:** a gizmo or camera drag went from 0.83 s per frame and 1.7 GB to about 9 ms per frame and 100 MB.
- **Hit testing:** `PaintList.topmost<T>(store, x, y)` now takes the storage, because of the erased-generic rule above.
- **New packages:**
  - `azora-scene`: Engine components (Transform, Mesh3d, Light3d, Camera3d, Sprite, Name, Visibility…) with the `@Inspectable` and `@Panel` annotations, plus scene AZON I/O (`io.az`).
  - `azora-ui-docking`: docking model and views.
    - Tabs, splits and drop zones, layout save and load.
    - **Floating windows:** moved by their bar and resized by a new corner grip (`DockFloatResize`).
    - `dockPointer(state, pass, front, back, …)` hit-tests floating windows first, so a press on a float never reaches the dock behind it.
  - `azora-gizmos`: `EditorCamera` (orbit, pan, zoom, focus, `lookAlong`, plus new **`look`** and **`fly`**) and `TransformGizmo` (move, rotate, scale, pick, drag).
- **Platform input:** middle mouse button, trackpad **pinch** (`App.pinch()`), and precise-scroll detection (`App.scrollIsPrecise()`).
- **Images and icons:**
  - `App.loadImage(path)` decodes PNG or JPEG through CoreGraphics into an `ImageTexture`.
  - `engine.ui.icons`: `loadIconAtlas(app, world, png, indexText)` installs an `IconAtlas` world resource, and `App.drawIcon(...)` draws one directly.
  - `engine.ui.node` gains `Icon(name, color, size)`, `ImageView(texture, modifier)`, and the `IconAtlas`, `IconGlyph` and `ImageFill` components. Paint ops 5 (icon) and 6 (image) were added.
- **Border alpha:** `Modifier.outline` now carries alpha (`ModifierKind.BorderAlpha`).
- **Other additions:**
  - Math: `formatDecimal`, `rotateEuler`, `trsMatrix`, `absValue`.
  - Draw: `meshSphere`, `uiLine`, `uiTriangle`.
  - UI: `Clip`, `FlowRow`, intrinsic (wrap-content) sizing.
- **Template metadata:** `template.azon` (title, category, description, icon, colour, order) added to `game-sidescroller-3d`, `game-racing`, `game-sidescroller-2d`, `game-tetris` and `app`.
- **Probes:** `tests/scene-io` and `tests/dock-layout` are new and pass; so do `scheduled-ecs` and `constructor-ui`. `owned-ecs` fails "world scope cleanup", but it fails at `e87375f` too (see §4).

- **Inspector:** reflection over Engine components, with editable fields. Numbers drag to scrub or click to type; text fields, enums and colours work.
- **Panels scroll:** `applyScroll` is now wired up.

## 5. Dev loop and rules

**User rules:**
- Commit only when asked.
- azora-lang: branch `0.1.0-dev`, never create branches.
- Receivers are written `func Type&.m()`.
- Prefer **`when` over `if`**.
- **Nothing hard-coded**: panels, components, menus, templates, theme, icons and file types come from reflection or data files.
- Use ECS and reactivity as much as possible.
- AZLS pastel palette.
- Launch Studio periodically so the user can try it.

**Build and run:**
```bash
# Compiler CLI (about 15 s)
cd azora-lang && ./gradlew :app:installDist --offline -q
# Native release compiler (online)
cd azora-lang && ./gradlew :compiler:linkReleaseExecutableMacosArm64
# Studio / launcher with the JVM CLI
AZORA_NATIVE_COMPILER=azora-lang/app/build/install/azora/bin/azora AZORA_STDLIB=azora-lang/std \
  bash azora-studio/native/tools/build-window.sh studio      # or launcher
# Run (builds too, with the release kexe)
bash azora-studio/native/tools/run.sh [studio|launcher] [/abs/project]
# Desktop shortcuts
bash azora-studio/native/tools/desktop-app.sh
# Icons atlas after editing resources/icons.azon
bash azora-studio/native/tools/build-icons.sh
# Engine probes
AZORA_NATIVE_COMPILER=<cli> azora-engine/tools/build.sh azora-engine/tests/<probe> build
```

**Verification without touching the user's mouse:**
- **Never post synthetic CGEvent clicks.** The user is at the machine. One landed in the Claude app on 2026-10-07.
- `AZORA_STUDIO_SCRIPT="wait 30; click X Y; move X Y; press X Y; release; rpress X Y; rrelease; scroll N; type txt; key N; meta N; command <declName>; shot name; quit"` with `AZORA_STUDIO_SHOTS=<dir>`.
  - Coordinates are content points: window points minus the 32 pt title bar.
  - The resource and project variables are `AZORA_STUDIO_RESOURCES=<native>/resources` and `AZORA_STUDIO_PROJECT=<native>/build/demo-project`.
  - `command windowResetLayout` resets docking.
- `AZORA_STUDIO_TRACE=1` prints pointer and hit traces.

**Performance and leak work:**
- Profile with `sample <pid>`.
- For leaks:
  1. Re-sign the binary with the `get-task-allow` entitlement.
  2. Add `"frame-pointer"="all"` to every `define` in `studio.ll` and link by hand.
  3. Run with `MallocStackLogging=1` and use `leaks <pid>`.
- AddressSanitizer: `AZORA_STUDIO_SANITIZER_FLAGS="-fsanitize=address -g"` with Apple clang. Leak detection is not supported on macOS.

**Benchmark:** a 30-step scripted drag should stay at about 9 ms per frame and about 100 MB peak.
